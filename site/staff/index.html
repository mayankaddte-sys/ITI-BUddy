Staff roles

adminEverything: add, edit, approve, archive and delete passages; read the chat log.
approverAdd and edit passages (they go live immediately), approve or archive pending passages, read the chat log.
editorAdd and edit passages. Their changes are saved as Pending and only reach trainees after an approver approves them.
viewerRead-only: see all passages and the chat log.

Users are invited and given roles by the site owner in the Netlify dashboard (Identity → Invite users, then open the user and set Roles).
